# TeamWork OpsPilot — Interactive Demo

A no-build, browser-only prototype for demonstrating operations automation to staffing agencies, payroll vendors, and HR teams.

## Open the demo
- Source: https://github.com/agentravan/agentravan/blob/main/index.html
- If GitHub Pages is enabled for this repository, the live URL is: https://agentravan.github.io/agentravan/

## Features
- Operations overview with synthetic KPIs and chart
- Simulated employee-data validation, follow-up draft, and MIS workflows
- Searchable work queue with editable demo statuses
- Local CSV validation in the browser
- CSV exports and editable pilot acceptance checklist
- Responsive desktop and mobile layout

## Important limitations
- This is a sales/demo prototype, not a production application.
- All built-in records and impact figures are synthetic/illustrative.
- No AI model, email, WhatsApp, payroll filing, HRMS, or external system integration is connected.
- CSV validation runs in the browser and the selected file is not uploaded by this page. Use only synthetic or non-sensitive data in the demo.
- No authentication, server database, audit trail, role-based access, or production security controls are implemented.
- Time-savings figures are hypotheses and must be measured with a client baseline before being presented as results.

## Run locally
Open `index.html` in a modern browser. No install or API key is required.

## Recommended paid pilot
Pick one client workflow, document its current effort and error rate, agree on acceptance criteria, use synthetic data for the demo, and scope secure production implementation separately. Do not promise statutory compliance outcomes without qualified review.
